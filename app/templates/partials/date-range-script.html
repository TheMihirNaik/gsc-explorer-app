{# Shared date-range picker wiring. Every report page had its own near-identical copy of this, which is how they drifted: default ranges of 7, 8, 28, 30 and 31 days across pages that all claimed the same thing, and a maxDate of today, which let people select days Search Console has no data for and then read the empty tail as a traffic drop. Include once per page, after a `#reportrange` trigger element and a form containing `#start_date` and `#end_date` hidden inputs. Set `default_days` before including to change the opening range (default 28). #}
